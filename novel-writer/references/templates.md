# 小说创作模板集合

本文件包含所有项目初始化所需的模板。

---

## 模板1：RULES.md

```markdown
# 小说写作项目规则

## 🎯 自动化执行协议

当你（未来的我）操作这个项目时，**必须**遵守以下规则：

### 启动时
1. 读取 `PROGRESS.md` 了解当前进度
2. 找到当前故事段和下一个待写章节

### 完成一章后（双层审核制）

#### 第一层：单章验收
1. ✅ 更新 `PROGRESS.md` 的状态和字数
2. ✅ **召唤审稿人审核本章**
3. ✅ 等待审稿结果：
   - ✅ 评分≥8分 → 通过，检查故事段是否完成
   - ⚠️ 评分<8分 → **立即按审稿意见修改**（不询问用户）
   - ❌ 修改后重新提交审核
4. ✅ 单章通过后，检查故事段状态：
   - ❌ 故事段未完成 → **立即开始下一章**
   - ✅ 故事段已完成 → 进入第二层审核

#### 第二层：故事段统一审核
1. ✅ 召唤审稿人批量审核整个故事段（例如1-4章）
2. ✅ 审核重点：整体节奏、情节连贯性、悬念递进
3. ✅ **自动修改规则**：
   - 审稿报告中标注 **【高优先级】必须修正** 的问题 → **立即修改**（不询问）
   - 审稿报告中标注 **【中优先级】建议调整** 的问题 → **立即修改**（不询问）
   - 审稿报告中标注 **【低优先级】建议优化** 的问题 → 可选修改
4. ✅ 修改完成后 → 继续下一个故事段

### 绝对禁止
- ❌ 写完一章不经审核就继续（必须等单章验收通过）
- ❌ 审稿人说"需修改"还继续下一章（必须先改完）
- ❌ 忘记更新 PROGRESS.md

---

## 📊 项目结构

```
第1章 → 审稿 → 通过
第2章 → 审稿 → 通过
第3章 → 审稿 → 通过
第4章 → 审稿 → 通过
↓
故事段1（1-4章）批量审核 → 修改 → 完成
↓
第5章 → 审稿 → 通过
第6章 → 审稿 → 通过
...
```

**双层保障：**
- **单章审核** - 保证每章质量，及时纠错
- **故事段审核** - 保证整体节奏和连贯性

---

## 🔥 执行纪律

**这不是建议，是协议。**

正确的执行节奏：
1. 写完一章 → 立即召唤审稿人
2. 等待审核结果（不要继续写）
3. 通过 → 检查故事段 → 未完成则立即写下一章
4. 需修改 → 修改 → 重新审核 → 通过后继续

**关键：每章必须通过验收才能继续下一章！**

---

*写给未来的自己：质量优先，不要跳过审核环节。*
```

## 使用说明

1. **初始化项目时**，根据用户需求选择合适的模板
2. **填充模板**中的 `{占位符}` 部分
3. **保存到项目目录**，文件名与模板标题一致（如 `RULES.md`）
4. **模板是起点**，创作过程中可以根据实际情况调整
